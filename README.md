# DictaDoc

Voice-to-document app. Speak once, get the document you need.

## Phase 1 scope
- One vertical (home care visit records or legal client memos)
- 3 templates
- Record -> transcribe -> generate -> PDF export

## Stack
- Next.js (App Router) + TypeScript + Tailwind
- OpenAI Whisper + GPT-4o
- Supabase (auth + DB + storage)

## Dev
```npm run dev```
